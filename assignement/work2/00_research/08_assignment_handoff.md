## โครงรายงาน 2 หน้า — ยังไม่ใช่เนื้อหารายงาน
หน้า 1: ชื่อ/บรรณานุกรมสั้น → ปัญหาและช่องว่าง → หลักการ/วิธีทำ → testbed/metric ที่ยืนยันจาก Full Text
หน้า 2: ผลสำคัญพร้อมหลักฐาน → contribution ที่เพิ่มจากงานเดิม → จุดเด่น/ข้อจำกัด → นำมาใช้กับ DivWy และอ้างอิง
ต้องรักษาพื้นที่ให้ contribution และการวิจารณ์ ไม่ใช้เกือบทั้งหมดกับบทนำ และไม่แปลทุกประโยคจนเกิน 2 หน้า

## Checklist สำหรับการตรวจรอบถัดไป
- [ ] PDF ตรง IEEE metadata และอ่านครบ ไม่ใช่ Abstract-only
- [ ] ทุกผลเชิงตัวเลขตามรอยกลับหน้า/ตารางได้
- [ ] ไม่เรียก citation count/full-text views ว่า metric ทดลอง
- [ ] แยกสิ่งที่ implemented / mock / dependency-only / future work
- [ ] ข้อวิจารณ์มีเหตุผลอ้างวิธีทดลอง ไม่ประดิษฐ์ข้อเสีย
- [ ] รายงานประมาณ 2 หน้าและสไลด์ 7 หน้าอ่านได้เมื่อฉาย
- [ ] ซ้อมพูด 5–8 นาที; ไม่ถือเวลาในตารางเป็นผลการซ้อมจริง
- [ ] ไม่มี secret หรือข้อมูลผู้ใช้จริงในเอกสาร
