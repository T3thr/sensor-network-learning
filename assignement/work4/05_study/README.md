## ข้อค้นพบที่ต้องรักษาไว้ในทุกชิ้นงาน

1. **คำถามวิจัย:** งานใดที่ทุกเบราว์เซอร์ต้องทำซ้ำ สามารถย้ายไปทำตอนเผยแพร่แล้วแจกจ่ายผลลัพธ์ร่วมกันได้บ้าง โดยวัดทั้งเวลาที่เห็นภาพและเวลาที่โต้ตอบได้
2. **ผลจริง:** ชุดปรับปรุงรวมใน Table 1 ลด TTR **83.7% ± 2.1**, ลด TTA **33.3% ± 9.6** และเพิ่ม SC **21.2% ± 29.9** เทียบกับ `none` เป็นค่าเฉลี่ยข้ามรูปแบบภาพและขนาดข้อมูล
3. **สาเหตุเชิงระบบ:** แคชและ materialized aggregates ลดภาระก่อนเปิดการโต้ตอบ ส่วนภาพเริ่มต้นที่เรนเดอร์ไว้ลดเวลาที่ผู้ใช้ต้องรอเห็นภาพ การเห็นภาพจึงมาก่อนความพร้อมใช้งานได้
4. **Hydration ที่ทำจริง:** Section 4.3 ใช้กระบวนการสร้างคอมโพเนนต์ฝั่งไคลเอนต์ตามปกติ Section 5 พบว่าค่าใช้จ่ายนี้เกือบเท่าการเรนเดอร์ฝั่งไคลเอนต์เต็มชุด Progressive / finer-grained hydration เป็นบริบทงานที่เกี่ยวข้องและแนวทางอนาคต
5. **ข้อสรุปจากการอ่าน:** ความสัมพันธ์ระหว่างกลไกเตรียมงานกับ TTR / TTA และพื้นที่ที่เพิ่มขึ้น เป็นข้อสรุปจากการอ่านบทความ
