## วิธีใช้กับ AI

เริ่มจากเอกสารหลักและเอกสารวิเคราะห์ แล้วใช้บทพูดประกอบการซ้อมใน [paper-4](../../../paper-4/index.html) สำหรับงานเชิงโปรแกรมให้อ่าน JSON อ้างอิง ซึ่งคัดข้อความของทั้ง 33 ช่วงและเก็บ SHA-256 ของเอกสารหลักไว้

เวลาช่วง podcast ให้อ้างตามไฟล์ที่ผู้ใช้แนบ ตัวเลขและข้อสรุปงานวิจัยให้อ้าง [paper ต้นฉบับ](../01_original/Paper_IV_1_PRIMARY_PublishTimeOpt_11298742.pdf) แยกผลของ Publish-Time ออกจาก Mosaic Selections และข้ออภิปรายเรื่อง Cloud ตามเอกสารวิเคราะห์

บทปัจจุบันจัดทำเป็น Markdown และอัปเดตข้อความเดียวกันในห้องซ้อมบนเว็บแล้ว เวลา 4:55 นาทีเป็นแผนที่ต้องตรวจด้วยการซ้อมพูดจริง
