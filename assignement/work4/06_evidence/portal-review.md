# ผลตรวจพอร์ทัล Paper IV

ตรวจวันที่ 7 ตุลาคม 2026 ด้วย Chromium ผ่าน Playwright CLI และเซิร์ฟเวอร์เฉพาะเครื่อง ภาพหน้าจอและสคริปต์ตรวจอยู่ใน `paper-4/output/playwright/`

## เนื้อหาและหลักฐาน

พอร์ทัลมี 12 ส่วน ศัพท์ 20 คำ คำถาม 15 ข้อ และแบบทดสอบ 5 ข้อ บทแปลมี 66 หน่วยเนื้อหาและหัวข้อ คู่กับระเบียนอ้างอิง 31 รายการ รวม 97 คู่ข้อความ ภาพ Figure 1–4 กับ Table 1 คงจากสำเนา PDF ที่ได้รับ ย่อหน้าต่อข้ามหน้ารวมไว้กับหน้าที่เริ่มต้นและระบุวิธีจัดหน้าไว้ในหน้าบทแปล

Table 1 รักษาค่าทั้ง 9 คู่พร้อม σ และฐาน `none` แยก `+most` ในตารางออกจาก `+prerender` ในกราฟ ผลต่าง TTA 1.0 เป็นจุดเปอร์เซ็นต์ ไม่มีข้อสรุปนัยสำคัญทางสถิติ Progressive hydration ไม่ถูกนำเสนอว่าเป็นระบบที่ทดลองแล้ว บริบท IoT และ CDN ระบุว่าเป็นการตีความต่อยอด

หน้าสุดท้ายของสไลด์แยกข้อสรุปจากการอ่านกับแนวทางที่คณะผู้วิจัยเสนอใน §5–6 (หน้า PDF 4) บทพูดใน PowerPoint เอกสาร Markdown และ Teleprompter ใช้ชุดข้อมูลเดียวกัน

## การทำงานที่ตรวจแล้ว

- การค้นศัพท์แสดงผลทันทีและมีสถานะไม่พบคำค้น
- ตัวเลือกการปรับปรุงสะสมถูกลำดับ ตัวจำลองใช้สูตรและสัดส่วน Table 1 ตามที่เปิดเผย ส่งผลลัพธ์ทันที และแสดงบันทึกขั้นตอนเรียงตามเวลา
- ห้องซ้อมเริ่ม หยุด รีเซ็ต ข้ามเวลา และเปลี่ยนสไลด์พร้อมบทพูดได้ นาฬิกาหยุดที่ 5:00 สไลด์เปลี่ยนอัตโนมัติเมื่อผ่าน 0:25 และ Teleprompter เลื่อนข้อความได้จริง
- ปุ่มลัด Space และลูกศร การเพิ่มขนาดบทพูด และการคงขนาดเมื่อเปลี่ยนสไลด์ทำงาน
- คำถามแบ่งหมวดได้ห้าข้อต่อหมวด เปิดคำตอบพร้อมแหล่งอ้างอิงได้
- ควิซชุดคำตอบผิดได้ 1/5 ชุดคำตอบถูกได้ 5/5 รีเซ็ตได้ครบ
- คัดลอก BibTeX ได้ ลิงก์เอกสารหลักทั้งสี่ตอบ HTTP 200
- บทแปลสลับสามโหมด ปรับขนาดอักษร ข้ามหน้า ติดตามหน้า และเปิดภาพขยายได้ โหมดไทยคงระเบียนอ้างอิงครบ
- ไม่พบ JavaScript runtime error หรือ console warning/error ในรอบที่ผ่าน
- ไม่พบการเลื่อนแนวนอนทั้งสองหน้าที่ 1440, 768 และ 390 px เพิ่มการตรวจพอร์ทัลที่ 320 และ 1920 px ด้วย ธีมสว่างและมืดตรวจจากภาพหน้าจอ
- ตรวจคำต้องห้ามและสรรพนามตามรายการที่กำหนดในไฟล์ HTML/CSS/JS/JSON ของพอร์ทัล ไม่พบข้อความที่ฝ่าฝืน

## ขอบเขตผลตรวจ

เวลาและ MB ในตัวจำลองเป็นค่าจำลองจากฐานที่กำหนด ไม่ใช่ข้อมูลดิบของ Figure 3 การแบ่งองค์ประกอบเวลาในตัวจำลองเป็นภาพอธิบาย ไม่ใช่ Figure 4 ที่วัดจริง แผนบทพูด 4:55 ยังไม่ใช่เวลาซ้อมพูดที่วัดจริง และการเลื่อนข้อความไม่ตรวจจับเสียง

เลขหน้าอ้างตำแหน่ง PDF หน้า 1–5 จากสำเนาผู้แต่งที่ได้รับ ไม่ใช่เลขหน้าพิมพ์ 226–230 ยังไม่ได้เปรียบเทียบรูปแบบกับ PDF ฉบับจัดพิมพ์ IEEE และไม่ได้เปิด PowerPoint รุ่นเดสก์ท็อปเพื่อตรวจระบบนำเสนอ
