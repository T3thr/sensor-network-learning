# รายงานฉบับย่อภาษาไทย Version 2: Raft-FL (SEAMS 2024, IEEE Doc ID: 10556381)
## 305432 เครือข่ายเซนเซอร์ (Sensor Networks) ภาควิชาวิศวกรรมไฟฟ้าและคอมพิวเตอร์ มหาวิทยาลัยนเรศวร

โฟลเดอร์นี้จัดเก็บรายงานฉบับย่อภาษาไทยของ Paper 3 Version 2 ความยาว 10 หน้า A4 จัดโครงสร้าง ภาษา และรูปแบบตามรายงาน Paper II (`../../work2/02_report/Assignment_Paper_2_StoryValidator_Short_Report_TH.pdf`) และ [REPORT_DESIGN_SYSTEM.md](../../../REPORT_DESIGN_SYSTEM.md)

### ไฟล์
- `Assignment_Paper_3_v2_Short_Report_TH.md`: ต้นฉบับเนื้อหา (แหล่งข้อมูลเดียวของทั้ง PDF และ DOCX)
- `Assignment_Paper_3_v2_Short_Report_TH.pdf`: ไฟล์สำหรับส่งตรวจ 10 หน้า
- `Assignment_Paper_3_v2_Short_Report_TH.docx`: ไฟล์ Microsoft Word ที่แก้ไขต่อได้

### โครงสร้าง 7 หัวข้อ
1. ข้อมูลผู้จัดทำและระเบียนบทความ
2. บทคัดย่อฉบับแปลและแรงจูงใจ
3. สถาปัตยกรรมและกลไก Raft Self-Recovery (ตารางที่ 1 ระดับการกู้คืน และภาพที่ 1)
4. การทดลองและผลลัพธ์ (ตารางที่ 2 ตัวเลขจาก Fig. 3 และ Fig. 4 หน้า 118)
5. การวิเคราะห์วิจารณ์เชิงวิศวกรรม (Contribution, จุดเด่น, จุดด้อยและข้อจำกัด)
6. ความเห็นและการนำไปประยุกต์ใช้กับงานจริง
7. เอกสารอ้างอิง [1] ถึง [7] แบบ IEEE ทุกรายการถูกอ้างในเนื้อหา

### รูปแบบ
- ฟอนต์ TH Sarabun (TH SarabunPSK) เนื้อหา 16 pt ระยะบรรทัด 1.6 (Word: ระยะบรรทัด 1.25 เท่าของความสูงฟอนต์ ซึ่งเทียบเท่ากัน) หัวข้อหลัก 18 pt หัวข้อย่อย 16 pt ตัวหนา
- ย่อหน้าชิดขอบสองด้าน ย่อบรรทัดแรก 0.45 นิ้ว ศัพท์เทคนิคภาษาอังกฤษอยู่ในวงเล็บหลังคำไทยเมื่อปรากฏครั้งแรก
- หัวข้อทุกหัวข้ออยู่หน้าเดียวกับเนื้อหาย่อหน้าแรก ตารางและภาพไม่ถูกตัดข้ามหน้า เลขหน้า "หน้า N" มุมขวาล่าง

### กฎการเขียน
1. ไม่มี Emoji
2. ไม่ใช้เครื่องหมายขีดยาว (Em Dash) ในประโยคภาษาไทย ใช้ทวิภาค (:) หรือวงเล็บแทน
3. ไม่ประดิษฐ์ศัพท์เทคนิคขึ้นเอง ใช้คำตามบทความและมาตรฐาน IEEE/ACM
4. ตัวเลขทุกตัวตรงกับบทความต้นฉบับ SEAMS 2024 หน้า 110 ถึง 121 และระบุหน้าที่มา
5. วิจารณ์ข้อจำกัดอย่างตรงไปตรงมา แยกสิ่งที่บทความวัดจริงออกจากสิ่งที่ผู้จัดทำคำนวณหรือตีความเพิ่ม
