# การค้นคว้าบทความวิจัย Assignment Paper 3 (Version 2 / Paper 3-2)
## 305432 เครือข่ายเซนเซอร์ (Sensor Networks) ภาควิชาวิศวกรรมไฟฟ้าและคอมพิวเตอร์ มหาวิทยาลัยนเรศวร

เอกสารฉบับนี้เป็นศูนย์กลางบันทึกการค้นคว้าและคัดเลือกบทความวิจัยรอบปรับปรุงใหม่ (Version 2) สำหรับ Assignment Paper 3 แทนที่บทความเดิม (OmniLedger, IEEE S&P 2018) เนื่องจากบทความเดิมมีเนื้อหาคณิตศาสตร์การเข้ารหัสและฉันทามติแบบแบ่งส่วน (Sharding Consensus) ที่ซับซ้อนเกินกว่าจะอธิบายที่มา ความสำคัญ และกลไกหลักให้ผู้ฟังเข้าใจได้ถ่องแท้ภายในเวลา 5 นาที อีกทั้งเป็นงานวิจัยที่ตีพิมพ์ก่อนปี 2024 ซึ่งไม่สะท้อนถึงภูมิทัศน์เทคโนโลยีในยุคปัญญาประดิษฐ์ (AI Era)

---

## 1. เหตุผลและความจำเป็นในการจัดทำ Version 2

1. **ความยากในการสื่อสารภายใน 5 นาที (5-Minute Presentation Feasibility):**
   - งานวิจัย OmniLedger มีกลไกถึง 4 ชั้นที่ทำงานซ้อนกัน (RandHound, ByzCoinX, Atomix, State Blocks) ทำให้สไลด์ 7 หน้ามีภาระทางปัญญา (Cognitive Load) สูงเกินไป ผู้ฟังไม่สามารถจับใจความสำคัญของปัญหาและแนวทางแก้ไขได้ทันใน 300 วินาที
   - Version 2 กำหนดให้บทความต้องมี "เส้นเรื่องและปัญหาที่เข้าใจได้ง่าย" (Clear Motivation and Relatable Problem) มีแผนภาพสถาปัตยกรรมที่อธิบายจบได้ใน 45 วินาที
2. **ความทันสมัยในยุคปัญญาประดิษฐ์ (Modern AI & Sensor Era, 2024+):**
   - เกณฑ์ใหม่กำหนดให้บทความต้องได้รับการตีพิมพ์ตั้งแต่ **ปี 2024 เป็นต้นไป (2024, 2025, 2026)**
   - สอดคล้องกับการประมวลผลเซนเซอร์ยุคใหม่ (Modern Sensor Networks), ระบบอัจฉริยะที่ขอบเครือข่าย (Edge Intelligence), การใช้แบบจำลองภาษาขนาดเล็ก/ใหญ่ (Edge AI / TinyML / LLM-assisted systems) หรือสถาปัตยกรรมกระจายตัวแบบ Event-Driven ในปัจจุบัน
3. **ความสอดคล้องกับอัตลักษณ์และทักษะของนิสิต (Authentic Student Competencies):**
   - เชื่อมโยงกับประสบการณ์จริงของนายธีรภัทร์ ภู่ระยา (Center): วิศวกรระบบแบ็กเอนด์ภาษา Go, สถาปัตยกรรม Microservices, Kafka Event Streaming, ความปลอดภัย Zero-Trust OIDC, และระบบเว็บสมัยใหม่

## 2. เกณฑ์การคัดเลือกบทความวิจัย Version 2 (Strict Screening Criteria)

1. **แหล่งที่มา:** ต้องเป็น Conference Paper จากฐานข้อมูลสากล IEEE Xplore โดยตรง
2. **ปีที่เผยแพร่:** ต้องเป็นบทความที่ตีพิมพ์ใน **ปี 2024 เป็นต้นไป (>= 2024)** เท่านั้น
3. **จำนวนบทความ:** ค้นคว้าและคัดกรอง 3 บทความ (PRIMARY 1 เรื่อง และ BACKUP 2 เรื่อง) พร้อมบันทึก DOI และ IEEE Document Number
4. **ความเข้าใจง่ายและศักยภาพการนำเสนอ 5 นาที:**
   - มีที่มาและปัญหาชัดเจน ไม่ต้องปูพื้นฐานทฤษฎีเฉพาะทางเกิน 1 นาที
   - มีแบบจำลองทางวิศวกรรมที่จับต้องได้ มีสูตรหรืออัลกอริทึมที่ไม่ซับซ้อนเกินไป
   - มีผลการทดลองเชิงประจักษ์ (Empirical Metrics) เช่น Latency, Throughput, Precision, Energy หรือ Memory Footprint พร้อมตารางเปรียบเทียบกับ Baseline
   - มีจุดเด่นและข้อจำกัดที่ยอมรับอย่างตรงไปตรงมา
5. **การไม่ซ้ำซ้อนกับงานที่ผ่านมา:**
   - ห้ามซ้ำกับ Paper I (IoT-CAD 9256703, MCSOA 10635077, ML-IoT Security 9826168)
   - ห้ามซ้ำกับ Paper II (StoryValidator 9618897, GENEVA 10645625, Serious Games 9826085)
   - ห้ามซ้ำกับ Paper III Version 1 (OmniLedger 8418625, FL Poisoning 9833647, Burglars' IoT 9152619)
